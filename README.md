# Python Placement Preparation

This repository records a four-week Python placement preparation programme. It contains beginner Python examples, intermediate Python practice, Git and GitHub workflow notes, and a tested command-line expense tracker.

## Weekly breakdown

- **Week 1:** Python basics, functions, and ten independent exercises.
- **Week 2:** OOP, modules, exceptions, files, JSON, and virtual environments.
- **Week 3:** Practical Git and GitHub documentation.
- **Week 4:** A JSON-backed CLI expense tracker with pytest tests.

## Technologies

Python 3, `argparse`, JSON, Git, and `pytest`.

## Repository structure

```text
Week-01-Python-Basics/
Week-02-Intermediate-Python/
Week-03-Git-and-GitHub/
Week-04-Expense-Tracker/
```

See each week's README for commands and details. The Week 4 application can be run from its directory with `python -m expense_tracker.main ...`.

## Installation

Python 3 is required. For the expense tracker, create and activate a virtual environment in `Week-04-Expense-Tracker`, then run `pip install -r requirements.txt`. The complete workflow is documented in that folder's README.

## Learning outcomes

The completed work demonstrates readable Python programs, reusable modules, basic object-oriented design, input and file error handling, JSON persistence, CLI argument parsing, testing, and common Git workflows.
