# Common Git commands

```bash
git init                         # create a repository
git status                       # inspect changes
git add <file>                   # stage a file
git commit -m "Describe change"  # save staged changes
git remote add origin <url>      # connect a remote
git push -u origin main         # publish a branch
git pull                         # fetch and integrate remote changes
git log --oneline                # view history
git branch                       # list branches
git switch -c feature/name       # create and switch branches
git merge feature/name           # merge a branch
```
